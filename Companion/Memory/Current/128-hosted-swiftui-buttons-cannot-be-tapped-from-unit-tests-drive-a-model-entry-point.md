## A hosted SwiftUI Button cannot be tapped from a unit test — publish no accessibility element, no UIView; test a control by driving a model entry point and inspecting the rendered hierarchy (2026-09-12, issue #110)

**Measured.** A SwiftUI `Button` hosted via `UIHostingController` in a `UIWindow` (made key and visible, `layoutIfNeeded`, polled for 2 s) publishes **zero** accessibility elements and **zero** UIView subviews in the `TabMailTests` process: the tree dump is `_UIHostingView<SignOutButton> isElement=false elements=0` with no children. `accessibilityActivate()` therefore has nothing to reach, and there is no `UIControl` to `sendActions` on. This repository has no ViewInspector dependency and no test that taps a SwiftUI button; do not spend build cycles rediscovering it (it cost three ~10-minute cycles on issue #110).

**What IS observable.** `ProgressView()` is backed by a `UIActivityIndicatorView` subview, so a spinner's presence/absence can be asserted by walking `window.subviews` after a short async poll (SwiftUI renders on a later run-loop turn than the hosting; a synchronous check right after hosting is vacuous). Text/`Label` content does NOT surface as `UILabel`s.

**The pattern that worked.** Move the control's action into a small `@Observable @MainActor` model with an injectable operation defaulting to the production call (`SignOutButtonModel.activate(onLocalFailure:)`, `perform:` defaulting to `TabMailAuthService.signOut()`). The view's button body is then a one-line call plus `.disabled(model.isSigningOut)`. Tests host the production view, call the model's entry point (the same one the button calls), hold the operation on a continuation, and inspect the rendered hierarchy across idle → pending → released. Pin the default operation separately inside the existing mocked harness (`SignOutHandshakeTests.defaultSignOutOperationRunsTheHandshake`), or a default of `{ true }` goes unnoticed. The residual untested glue is the SwiftUI `Button` closure and `.disabled` modifier — framework contracts; the round-4 reviewer accepted that as the floor.

**Reference tests.** `SignOutButtonTests`, `SignOutButtonLabelTests`, `SignOutHandshakeTests` (issue #110 section). Red proofs that defined the coverage: label reverted to static, in-flight state released early, re-entry guard removed, failure callback dropped, default operation replaced by `{ true }`.
