
### Backfill diagnostics: `backfill.log` channel (2026-07-02)
- Key backfill lifecycle events now route through **`BackgroundSyncLogger.logBackfill`** → `backfill.log` (debug-gated, exported as "Backfill Logs" in the Debug menu): walk worker START/EXIT, cycle start+profile, pause reasons (low-battery / WiFi-only-on-cellular), folder fully-crawled, failed-range retries, connection-failure backoff, learned server connection limit, body-queue repopulate/batch DONE/FAILED, miss/confirm-gone/re-key outcomes. Fine-grained per-chunk logging (`[UIDCursor]`, SEARCH found counts, dispatch internals) remains `print()`-only (console). Historical note: before 2026-07-02 ALL backfill logging was print()-only, so exported logs showed nothing about backfill stalls; `backfill_ai_logs.txt` is the **BackfillAIQueue** (AI), not the header/body backfill.
